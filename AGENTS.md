# AGENTS.md — правила для агентов (ZCode, Claude Code, Codex), работающих в этом репозитории

Этот файл читают coding-агенты. Он описывает жёсткие правила проекта; они
существуют потому, что нарушение каждого из них уже приводило к реальной поломке
или к ложным выводам в замерах.

## Что это за проект

Laya Engine — локальный HTTP-сервис типизированных решений (`choice` / `score` /
`noul`) на модели Laya (~322M, ONNX). Go + ONNX Runtime, без Python в рантайме.
Всё живёт на loopback `127.0.0.1:8095`. Рядом — демо `laya_arcade/` и интеграция
с ZCode (плагин в отдельном репозитории, см. `integrations/zcode/README.md`).

## Незыблемые правила

1. **Ничего не скачивать в рантайме.** `start-laya*` только читает локальные
   файлы и падает с внятной ошибкой, если чего-то нет. За скачивание отвечают
   только `scripts/fetch-*` (это одноразовые установочные скрипты).
2. **Молчаливый откат CUDA→CPU запрещён.** `-allow-cpu-fallback` выключен
   намеренно: однажды «замеры на GPU» на самом деле шли на CPU. Не включай его в
   скриптах и не добавляй автоматический retry с CPU.
3. **Вероятность — не доказательство.** Ответы модели не должны расширять
   разрешения и не должны заменять факты (`git status`, коды возврата тестов).
4. **Состояние режется справа.** Если `budget.state_truncated` или
   `state_dropped > 0` — модель не видела хвост текста. Решающие факты — в начало
   состояния. Не «чини» это сдвигом обрезки: контракт зафиксирован.
5. **Порог ставь по `answer_confidence`** (= max(p), калибрована температурой).
   `confidence` (энтропия) не калибрована, `act_probability` насыщена — не
   использовать как сигнал.
6. **Чекпоинт — часть контракта.** Пороги, замеры и логи привязываются к
   `multilingual-fp16-0b095e005a4c` (см. `/info`). Подмена весов без смены id
   невозможна и недопустима.
7. **INT8-экспорт не использовать.** `models/multilingual-int8.onnx` испорчен
   квантованием головы (симптом: уверенность ≈ 1/k у всех вопросов). Причина
   разобрана в `docs/ENGINE.ru.md`.
8. **Windows-скрипты: только ASCII + CRLF.** `.cmd` с LF ломает cmd.exe; кириллица
   ломает парсер на некоторых кодовых страницах. `.gitattributes` это фиксирует —
   не пересохраняй такие файлы в UTF-8/LF.
9. **Секреты не коммитить.** Токены доступа — только в переменных окружения.

## Как проверять изменения

```bash
# быстрый цикл (модель не нужна)
gofmt -l . && go vet ./... && go test ./...

# полная сборка (нужен gcc: cgo)
./build.cmd              # Windows
./scripts/build.sh       # Linux/macOS
```

Тяжёлые тесты (сверка с Python-эталоном, загрузка весов) включаются только явно:
`LAYA_HEAVY=1 go test ./engine/ -run Reference`.

## Стиль

- Комментарии и документация — по-русски (основной язык проекта), код и
  идентификаторы — английские. Публичный README двуязычный.
- Комментарий объясняет **почему**, а не **что**: история решений (почему выключен
  fallback, почему INT8 запрещён) — часть кода.
- Замеры не выдумывать: числа берутся из `docs/BENCHMARKS.md` и
  `davinci-laya-decisions/docs/AB-RESULTS.md` (репозиторий плагина).
